### 주요 결정 사항
- 스크린샷 모드 2종: 실행 옵션(`--dart-define=HIDE_DEBUG_UI=true`) + 설정 탭 스위치(디버그 전용, `DebugUiProvider`). 디버그 리본은 항상 숨김.
- 온보딩 스크린샷 8장: `seed_locked/growing`, `fruit_complete`, `review_empty/filled`, `archive_garden`, `settings`, `settings_seed_time`. `assets/images/`만으로는 하위 폴더가 번들에 안 들어가서 `assets/images/screenshots/` 명시 등록 + `screenshot_assets_test.dart` 회귀 테스트.
- Pages 지원 경로는 `support/index.html` (`/malssi/support/`). Pages는 머지 후 Settings에서 직접 켜야 함 (아직 안 켬).
- `ci_scripts` 위치는 저장소 루트가 아니라 `ios/` 옆. 루트에 두면 Cloud가 못 찾음.
- 앱 아이콘: 크롭 실험 후 그라데이션 풀블리드 원본 채택. 소스는 `assets/icon/`에 보관 (pubspec 등록 안 함, 앱 용량 제외).
- 실기기 서명 오류는 계정 기기 미등록이 원인. UDID는 USB 연결 후 Finder 일련번호 클릭 또는 Xcode Devices에서 확인 (Wi-Fi 연결만으로는 불가).
- Xcode Cloud export 실패(`Development/Ad Hoc`)는 서명 문제로, 경고 7개(서드파티 deprecation 등)는 무해.
